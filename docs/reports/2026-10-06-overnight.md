## 1. Refactor และ performance

**หลักที่ใช้:** การเล่นต้องไม่เปลี่ยนแม้แต่นิดเดียว เซฟยังเป็นเวอร์ชัน 25 รูปเดิม และไม่แตะตัวเลขเกม

### สิ่งที่ทำ

1. **แยก `store/world-store.ts` (3,631 บรรทัด)**
   - ตัวไฟล์เหลือ 90 บรรทัด ทำหน้าที่ประกอบ store อย่างเดียว
   - โค้ดย้ายไปอยู่ใน `store/world/`:
     - `state`: ค่าเริ่มต้นของเกม
     - `rules`: ค่าปรับสมดุล
     - `progression`: xp / เลเวล
     - `lifecycle`: เวลา ความตาย การฆ่า
     - `navigation`: การเดินทาง
     - `spoils`: ของที่ได้จากการต่อสู้
     - `persist`: การเซฟและแปลงเซฟ
     - `actions/`: 13 ไฟล์ แยกตามระบบ (สำนัก กฎหมาย ร้านค้า จดหมาย ประลอง ฯลฯ)
   - ชื่อ action และ API ภายนอกเหมือนเดิมทุกตัว ใช้สคริปต์ย้ายโค้ด แล้วเทียบดูว่าต่างกันแค่บรรทัด import กับโครง
   - ผลคือแก้ระบบไหนก็เปิดแค่ไฟล์ของระบบนั้น
2. **เพิ่ม index ให้การค้นหา**
   - เดิมหน้าแผนที่ไล่ค้นเควสทั้ง 1,115 อันและ NPC ทั้ง 235 คน ทุกคนบนแผนที่ ทุกครั้งที่วาด
   - ตอนนี้สร้างตารางค้นหาครั้งเดียวตอนโหลด และระบบนำทางจำเส้นทางที่คำนวณไว้แล้ว

   | วัดด้วย `bun scripts/bench-world.ts` | ก่อน | หลัง |
   | --- | --- | --- |
   | งานหน้าแผนที่ นครหลวง (เกมใหม่) | 561 µs | 168 µs |
   | งานหน้าแผนที่ นครหลวง (เล่นไป 1 ปี) | 667 µs | 290 µs |
   | คำนวณลูกศรนำทาง (เกมใหม่) | 63 µs | 17 µs |
   | คำนวณลูกศรนำทาง (เล่นไป 1 ปี) | 55 µs | 5 µs |
3. **ให้ compiler ช่วยจับบั๊ก**
   - เดิมถ้าเพิ่ม effect หรือ reward ชนิดใหม่แล้วลืมเขียน case เกมจะ build ผ่าน แต่ effect นั้นไม่ทำอะไรเลย ตอนนี้จะ typecheck ไม่ผ่านทันที
   - ใช้กับตัวจัดการ effect ของฉาก, รางวัลเควส, effect การต่อสู้ทั้ง 3 ตัว และท่าออกพลังของวิชาในกาย
   - ถ้าเพิ่ม field ในเซฟแล้วลืมใส่ในรายการที่ต้องเซฟ ก็ typecheck ไม่ผ่านเช่นกัน
4. **จัดโค้ดให้อยู่ที่ควรอยู่**
   - ระบบเจอศัตรูระหว่างเดินแยกไปไฟล์ `lib/world/encounters.ts`
   - การสุ่มของดรอปกับของที่เก็บได้ใช้ฟังก์ชันเดียวกัน ผลสุ่มยังเหมือนเดิมทุกครั้ง
5. **เครื่องมือใหม่**
   - `scripts/golden-replay.ts` เล่นเกมอัตโนมัติด้วย seed คงที่ ผ่านเกือบทุก action แล้ว hash สถานะหลังแต่ละขั้น
     - ผลออกมาเหมือนเดิมทุกไบต์ ทั้งก่อน refactor และหลังทุก commit
     - คราวหน้าจะ refactor อะไร ให้รันตัวนี้ก่อนและหลัง
   - `scripts/bench-world.ts` และ `scripts/bench-browser.ts` สำหรับวัด performance

### สิ่งที่วัดแล้ว แต่ตั้งใจไม่ทำ (เสี่ยงเกินกว่าจะทำตอนไม่มีคนดู หรือได้ผลน้อย)

- **ลดการเขียนเซฟ:** แต่ละครั้งใช้แค่ 0.3–0.6 ms และเกิดเฉพาะตอนกดทำอะไร ไม่ได้เกิดทุกเฟรม
- **หน้าแผนที่ช้า:** JS ใช้แค่ราว 2 ms ต่อเฟรม เวลาเกือบทั้งหมดอยู่ที่การวาดภาพ ไม่ใช่โค้ดเกม
- **แยก `world-runtime.ts` / `grid-battle-runtime.ts`:** ต้องทดสอบบนเบราว์เซอร์อย่างละเอียดก่อน
- **โหลดเนื้อหาทีละส่วน (lazy load):** ไฟล์แรกที่โหลดใหญ่เพราะเนื้อหาเควสกับเนื้อเรื่อง ต้องเปลี่ยนโครงสร้างระดับสถาปัตยกรรม

## 2. บทเควส: ผู้เล่นที่ไม่รู้อะไรมาก่อนจะเข้าใจไหม

ตรวจทุกเควสด้วยคำถาม 4 ข้อ: **ใคร**ขอ **ทำไม**ต้องทำ ต้อง**ทำอะไร** และไป**ที่ไหน** แก้เฉพาะข้อความ ไม่แตะกลไกเควส

ขั้นตอนเควสที่บอกสถานที่ ตอนนี้ใช้ชื่อเดียวกับในแผนที่เป๊ะๆ เพราะลูกศรนำทางหาเป้าหมายจากชื่อในข้อความ

### ปริมาณงาน

| ส่วน | รีวิว | แก้ |
| --- | --- | --- |
| เนื้อเรื่องหลัก 15 บท | 15 | ~13 |
| เควสในเมือง | 27 | ~25 |
| เควสหมู่บ้าน / โรงเตี๊ยม | 24 | ~24 |
| เควสป่าเขา | 25 | ~24 |
| เควสสายมาร | 47 | ~40 |
| เควสสายลับ | 15 | ~13 |
| เควสประจำสถานที่ | 66 | 6 (ส่วนใหญ่ดีอยู่แล้ว) |
| เควสสำนัก | ~120 | ~110 |
| บทสนทนาสำนัก | ~250 ฉาก | ~45 บรรทัด |
| เควสสายวิชา (แม่แบบ) | 154 | ทั้งหมด (แก้แม่แบบจุดเดียว) |
| saga | บทที่ 1–2 ทั้ง 48 เรื่องอ่านละเอียด, คำใบ้ทั้ง 1,001 จุดตรวจด้วยสคริปต์ | คำใบ้ ~90 จุด + แนะนำตัวละครในนิยาย |

### ปัญหาที่เจอบ่อย (ตัวอย่างก่อน → หลัง)

1. **รหัสภายในหรือภาษาอังกฤษหลุดมาให้ผู้เล่นเห็น**
   - `ปราบหัวหน้าโจร (bandit_chief) 2 คน` → `ปราบหัวหน้าโจร 2 คน`
   - `นำของถวาย — ginseng 5 ชิ้น` → `นำโสม 5 รากมาถวาย`
   - `(INT ≥ 45)` → `(ฉลาด ≥ 45)`
   - `30 WEXP`, `มาสเตอร์รี่`, `เช็คเอาท์`, `ขั้นตอน: 1) … 2) …` → เขียนเป็นภาษาไทยธรรมดา
   - มีตัวอักษรเกาหลีหลุดอยู่ในตัวเลือกด้วย (`ตามม양จิตใจ`) แก้แล้ว
2. **ไม่บอกว่าใครหรือไปที่ไหน**
   - `ไปถามคนที่ช่วยพ่อเจ้าส่งของ` → `… — อาจารย์ข่าวสารยุนซือที่พรรคยาจก`
     - เนื้อเรื่องหลักบทที่ 11 เดิมไม่มีทางรู้เลยว่าต้องไปหาใคร
   - `รายงานหยิง` → `กลับไปรายงานนักฆ่าเงาหยิงที่ถ้ำแมงมุม`
   - ป้าหลิว ลุงโจว อาหนิว มีบรรทัดแนะนำตัวตอนพบครั้งแรก
3. **ข้อความสัญญาสิ่งที่เควสไม่ได้ตรวจจริง**
   - `เก็บดอกไม้ขมห้าดอก` แต่เควสต้องการเม็ดบัว → `เก็บเม็ดบัว 3 เม็ด`
   - `ปราบหมาป่าสักสามตัว` แต่ระบบนับ 2 → แก้เป็น 2
   - บทเข้าสำนักทุกสำนักเคยบอกว่า "รับวิชา X เป็นวิชาแรก" แต่การเลื่อนขั้นไม่ได้ให้วิชาจริง → เปลี่ยนเป็น "ศิษย์พี่จะสอนทีละขั้น"
4. **เควสสายวิชาไม่บอกงานทั้งหมด**
   - ก่อน: `Xยินดีถ่ายทอดวิชาลึกลับให้ผู้ที่พิสูจน์ตนได้`
   - หลัง: `Xแห่ง<สำนัก>จะถ่ายทอดวิชาลึกลับให้ เมื่อพิสูจน์ตนได้: ปราบ<ศัตรู> 3 ครั้ง หา<ของ> 3 ชิ้น แล้วชนะการประลองกับท่าน`
   - ขั้นประลองบอกให้ไปกด "ขอประลอง" ด้วย
5. **ชื่อไม่ตรงกับแผนที่ ย่าม หรือ NPC**
   - `เหล็กดิบ` → `แร่เหล็ก`
   - `วัดตาหลุน` → `วิหารล้อลม`
   - `ท่านนิ้วจิงฉาน` → `ท่านนิ้วห้วนจิงฉาน`
   - ภูเขาขาวอูต → **ภูเขาอูฐขาว** (แก้ในตารางสถานที่ด้วย)
6. **ตัวละครจากนิยายโผล่มาโดยไม่มีการแนะนำ:** เพิ่มบรรทัดแนะนำตอนเปิดบทของ saga เช่น ราชสีห์ขนทอง และเจียซุ่นกับพระสามรูป
7. **ลูกศรนำทางชี้ผิดคน:** เควสบัญชีหายในนครหลวงเคยชี้ไปที่เสมียน แทนที่จะชี้ไปที่นายอำเภอหวู่ แก้แล้ว พร้อมอีก 3 เควส
8. **เรียกตัวเอกด้วยคำที่ระบุเพศ** เช่น `เจ้าหนุ่ม`, `ขอรับ` → ใช้คำกลางๆ

นอกจากนี้ หน้าต่างสำนักเปลี่ยน "sect points" เป็น **แต้มสำนัก** ให้ตรงกับในเควส

## 3. สิ่งที่เจอแต่ยังไม่ได้แก้ (ต้องให้คุณตัดสินใจ)

agent แก้ข้อความให้ตรงกับกลไกเกมไปก่อนแล้ว รายการเต็มอยู่ใน `HANDOFF.md` หัวข้อ Quests and sects ข้อ 8

1. **ชื่อในแผนที่ไม่ตรงกับชื่อในเนื้อเรื่อง** ควรเปลี่ยนชื่อในแผนที่ให้ตรงเนื้อเรื่องไหม?
   - โรงเตี๊ยมห้วอลั่ว (เนื้อเรื่องเรียก เฮ่อลั่ว)
   - โรงเตี๊ยมเก้าอี้สูง (เกาเซิ่ง)
   - วิหารล้อลม (วัดตาหลุน)
   - คุ้มนกนางแอ่น (คฤหาสน์เหยินซี)
   - มังกรดำสระน้ำ (สระมังกรดำ)
   - หน้าผาหินอาถรรพ์ (ผาสำนึกผิด)
2. **NPC ชื่อซ้ำ:** มี "ลุงไป๋" สองคน ทำให้ลูกศรนำทางสับสนได้
3. **บทเสนอเควสแบบเก่าเล่นหลังกดรับเควสไปแล้ว** ตัวเลือก "ปฏิเสธ" ในบทพวกนั้นจึงไม่มีผล
4. **บทสนทนาราว 16 ฉากไม่เคยถูกเล่น** เพราะเควสพวกนั้นเดินหน้าด้วยจุดค้นหรือการไปถึงสถานที่แทน
   - ที่สำคัญคือ `qw_motian_restless_soul`: ตัวเลือก "เก็บดาบไว้หรือคืน" ไม่เคยแสดง
5. **เควสที่กลไกแปลก**
   - `qv_hengshan_winter_aid` ผ่านได้ก็ต่อเมื่อในย่ามไม่มีข้าวหมูแดงและยาเลือดเล็กเลย และไม่มีที่ให้ส่งของ
   - `qw_desert_relic_return` ไม่มีที่ให้ส่งเหรียญ
   - `qc_capital_stolen_formula` ต้องใช้ตำราขั้นสูงราคา 800 ตำลึง แพงไปสำหรับงานช่วยหมอ
6. **เควสสายลับ 2 เควสมีรางวัลทอง 400 ซ้ำสองบรรทัด** ไม่แน่ใจว่าตั้งใจให้เป็นโบนัส หรือพิมพ์ซ้ำ
7. **`qst_shaolin_wudang_joint`** มี 2 ขั้นที่ไม่บอกสถานที่ และตัวเลือกเดียวข้ามได้ทั้งสองขั้น
8. **ชื่อผู้พูดในบทสนทนาป่าเขากับสายมารเป็นชื่อสั้น** ไม่ตรงกับชื่อเต็มของ NPC รูป portrait อาจไม่ขึ้น
9. **saga บทที่ 3 เป็นต้นไป** ตรวจด้วยสคริปต์อย่างเดียว ยังไม่ได้อ่านทีละบรรทัด
